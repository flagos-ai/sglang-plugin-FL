# Application-level constraints for the Hygon CI image build.
#
# Deliberately tiny: the SGLang wheel's own METADATA already pins its direct
# dependencies (blobfile==3.0.0, openai==2.6.1, outlines==0.1.11,
# transformers==5.12.1, xgrammar==0.2.1, ...), and the operations runtime's
# live inventory is frozen dynamically at build start
# (runtime-constraints.txt from runtime-distributions-before.json), so every
# runtime distribution is unpipinstallable and transitive resolution belongs
# to the resolver. The full resolved closure is recorded at build time as an
# audit artifact (/opt/sglang-ci/sglang-additions-installed.txt) and is never
# committed back as an input lock.
#
# Only pins with concrete failure evidence belong here:
#
# datasets==5.2.0 - the runtime ships fsspec 2026.9.0, which every older
#   datasets release carried by the pypi-proxy caps below (ResolutionImpossible
#   during the original resolver runs); 5.2.0 is the first release allowing
#   the runtime's fsspec. Without this pin the resolver backtracks to an
#   unsatisfiable plan on the platform index alone.
datasets==5.2.0
